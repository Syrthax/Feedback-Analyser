Customer feedback analyser · built on Hindsight memory

Feedback that remembers.

Give it a business name and a location. It reads the public reviews, throws away the junk, groups what's left into themes and scores each one from −5 to +5 with a reason and a next step. Every run is remembered, so the next one can say what got better and what got worse.

Three questions a star rating can't answer.

An average of 4.3★ says nothing about what to do on Monday. The analyser turns reviews into a ranked list of what to fix and what to protect, and remembers each run so the next one can say what changed.

Triage · −5

What should I fix first?

Every theme gets a score from −5 to +5. The negatives are problems ranked by urgency, and −5 is the one to work on before anything else.

Protect · +5

What should I not break?

The positives are strengths ranked by how much they matter. +5 is the single best thing, the one to keep exactly as it is.

Memory

Is it getting better or worse?

Themes get reworded between runs: “pricing and affordability” one month, “pricing reasonableness” the next. Hindsight's recall is semantic, so it bridges the rename and the Analyst still cites the earlier figure.

Five stages, one memory.

Each stage hands the next a plain list, so any one can be swapped without touching the others. The last two are why a run can explain a change instead of just reporting it.
